🕵️‍♂️ AI 명탐정 미션 (학생 화면)

선생님이 지정한 미션을 선택하고, 목표 그림과 똑같이 단어를 조합해 그림을 그려보세요!

🎯 목표 그림

미션을 선택하면 선생님이 올린 그림이 나타납니다.

🎨 나의 AI 그림

버튼을 누르면 AI가 그림을 그립니다.

👨‍🏫 선생님 모드 로그인

⚙️ 선생님 설정 (관리자)

🔑 Gemini API Key 저장

선생님의 기기(브라우저)에 API 키를 저장하여 학생들의 이미지 생성을 지원합니다.

📸 미션 그림 클라우드 등록 (Firebase 연동)

여기에 등록한 이미지는 공유 링크를 통해 학생들의 화면에 실시간으로 자동 반영됩니다.
